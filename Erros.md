Mas só se você parar de cometer esses 17 erros:

1: Você envia PDFs raw. Uma página = 3.000 fichas.
Correção: Cole o texto em um documento do Google. Baixe no formato .md. Menos de 200 tokens.

2: Você cria arquivos dentro do Cowork cedo demais.
Correção: Planeje primeiro no Chat. Mude para o Cowork somente quando souber exatamente o que quer.

3: Você escreve prompts de 500 palavras que recarregam.
Correção: Escreva 29 palavras em vez disso: "Quero [tarefa] para [objetivo]. Me faça perguntas usando o AskUserQuestion."

4: Você diz "refaça tudo" para corrigir a parte 3.
Correção: "Só refaça a seção 3. Fique com todo o resto. Sem comentários. Só a saída."

5: Você envia 3 mensagens separadas para 3 tarefas. 
Correção: Uma mensagem, três tarefas. "Resuma isso, liste os pontos, sugira uma manchete."

6: Você digita "Não, eu quis dizer", empilhando o histórico.
Correção: Clique em 'Editar' na sua mensagem original. Conserte. Regenerar. História substituída, não adicionada.

7: Você usa o modelo Opus para uma verificação gramatical. 
Correção: Soneto ou Haiku para tarefas rápidas. Guarde Opus + Pensamento Estendido para trabalho profundo.

8: Você despeja 50 arquivos no Cowork "por precaução."
Correção: Inclua apenas o que essa tarefa precisa. Zero pastas para tarefas rápidas como rascunhos de e-mail.

9: Você nunca recomeça do zero e continua tendo longas conversas.
Correção: A cada 15-20 mensagens → resumo, copie o resumo, comece uma nova sessão.

10: Você mantém 3 tópicos em 1 chat. Claude relê tudo.
Correção: Novo tópico = novo chat. Sempre. Contexto morto são tokens mortos.

11: Seu arquivo sobre mim tem 22.000 palavras (muito longo).
Correção: Reduzir para menos de 2.000 palavras. Encerre as sessões com "Escreva uma sessão anotações .md."

12: Você deixa a busca e conectores ativados por padrão.
Correção: Desativar tudo por padrão. Ative recursos por tarefa, não por conta.

13: Você envia o mesmo PDF para 5 chats diferentes. 
Correção: Use projetos. Faça upload uma vez. Cada chat dentro faz referência a isso sem queimar tokens novamente.

14: Você pula Preferências Pessoais e configuração de desperdício.
Correção: Configurações → Preferências Pessoais. Defina seu tom e estilo uma vez. Persiste para sempre.

15: Você reescreve os prompts do zero toda vez.
Correção: Mantenha uma biblioteca de prompts. Mesma estrutura, troque a variável. Prompts estáveis são armazenados em cache.

16: Você roda manualmente o mesmo relatório toda semana.
Correção: Use /schedule. "Toda segunda-feira às 7h, crie meu briefing semanal." Acordar com um documento finalizado.

17: Você usa Claude para coisas que ele não pode fazer.
Correção: Conheça suas ferramentas. Imagens → Gêmeos. 
Busca em tempo real → Grok. 
Parem de queimar fichas em becos sem saída.
